# Test cases: Public landing page for unauthenticated visitors

Every case traces to a scenario in `acceptance-criteria.md`. Priorities: **P1** breaks the
core convert-or-sign-in flow or leaks information; **P2** degrades an important path;
**P3** cosmetic or rare.

| ID | Title | Type | Linked scenario | Preconditions | Steps | Test data | Expected result | Priority |
